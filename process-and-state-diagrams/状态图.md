# 在线购物系统状态图

以下状态依据完整需求绘制。“交易失败后恢复在售”作为单独业务阶段展示，其接收意向、开始交易、手动冻结和主动下架的权限与普通在售相同。

## 1. 商品状态

```mermaid
stateDiagram-v2
    [*] --> OnSale: 卖家发布商品
    state "在售" as OnSale
    state "手动冻结" as ManualFrozen
    state "交易冻结" as TradeFrozen
    state "已恢复在售" as Restored
    state "商品下架" as Delisted

    OnSale --> ManualFrozen: 卖家手动冻结
    Restored --> ManualFrozen: 卖家手动冻结
    ManualFrozen --> OnSale: 卖家解冻
    OnSale --> TradeFrozen: 卖家开始交易／系统选队首
    Restored --> TradeFrozen: 卖家开始交易／系统选队首
    TradeFrozen --> Restored: 交易失败并完成处置
    TradeFrozen --> Delisted: 交易成功／自动下架、删除视频
    OnSale --> Delisted: 卖家主动下架／删除视频
    Restored --> Delisted: 卖家主动下架／删除视频
    Delisted --> [*]: 结束当前商品流程
```

手动冻结暂停新意向，但不生成交易结果；解冻后继续可售。交易冻结须先登记结果，不能直接解冻或下架。手动冻结须先解冻才能主动下架。下架后可以发布下一件商品，原商品的历史记录仍保留。

## 2. 购买意向状态

```mermaid
stateDiagram-v2
    [*] --> Waiting: 买家提交姓名和电话，系统生成口令码
    state "排队中" as Waiting
    state "交易中" as InTrade
    state "交易成功" as Success
    state "交易失败" as Failed
    state "已作废" as Voided
    state "已撤销" as Cancelled
    state "商品下架而终止" as ProductDelisted

    Waiting --> Waiting: 买家修改联系信息／排位不变
    Waiting --> Waiting: 卖家移到队尾／刷新排队时间、原码有效
    Waiting --> Cancelled: 买家撤销／原码失效
    Waiting --> Voided: 卖家作废等待意向／原码失效
    Waiting --> InTrade: 卖家开始交易／系统选队首
    InTrade --> Success: 交易成功／原码失效
    InTrade --> Voided: 交易失败并作废／记录失败、原码失效
    InTrade --> Waiting: 交易失败并重新排队／记录失败、原码有效
    Waiting --> Failed: 其他买家交易成功／原码失效
    Waiting --> ProductDelisted: 卖家主动下架／原码失效

    Success --> [*]
    Failed --> [*]
    Voided --> [*]
    Cancelled --> [*]
    ProductDelisted --> [*]
```

交易失败后必须在同一次操作中选择“作废”或“重新排队”，图中不把等待处置的失败结果画成可停留的状态。失败结果和处置均写入历史。冻结影响商品是否接收新意向，不改变现有等待买家的“排队中”状态；等待买家在冻结期间仍可查询、修改联系信息和撤销。

## 3. 口令码有效性

```mermaid
stateDiagram-v2
    [*] --> Valid: 提交意向时生成并绑定唯一口令码
    state "有效" as Valid
    state "失效" as Invalid

    Valid --> Valid: 排队、手动冻结、交易冻结期间查询
    Valid --> Valid: 修改联系信息或重新排到队尾
    Valid --> Invalid: 买家撤销或卖家作废
    Valid --> Invalid: 本次交易成功或其他买家成交
    Valid --> Invalid: 商品主动下架
    Invalid --> [*]: 买家不能再凭原码查询或管理意向
```

重新排队使用原意向、原口令码，不重新生成。口令码失效不删除历史中的姓名、电话和交易记录；卖家历史页面不展示口令码。
