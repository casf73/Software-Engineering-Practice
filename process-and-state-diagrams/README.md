## 统一业务约定

1. 同一时间仅有一件当前商品。卖家发布后直接在售；交易成功或主动下架后可发布下一件。
2. 买家免注册提交姓名和电话，系统生成唯一口令码；有效意向按服务端提交时间先后排队。
3. 卖家决定何时开始交易；系统只选当前队首，不允许指定或跳过其他买家。
4. 商品手动冻结或交易冻结期间不接收新意向；尚未进入交易的等待买家仍可查询、修改联系信息或撤销。
5. 交易失败时卖家须同时选择作废或重新排队；重新排队沿用原意向和原口令码。
6. 历史记录按商品组织，交易失败后商品即使恢复在售也保留历史记录；商品下架时自动删除展示视频，历史业务记录继续保留。
