# 在线购物系统业务流程图

以下流程依据《在线购物系统需求规格说明书》，覆盖完整项目的买家、卖家和系统处理。交易在线下完成，系统负责排队、冻结、登记结果与保存历史。

## 1. 商品与交易主流程

```mermaid
flowchart TD
    A[卖家登录后台] --> B{是否已有当前商品}
    B -- 否 --> C[填写名称、价格及可选描述、图片、视频、分类和标签]
    C --> D[发布商品，状态为在售]
    B -- 是 --> E[查看并管理当前商品]
    D --> E
    E --> F{卖家操作}
    F -- 编辑商品 --> E
    F -- 手动冻结 --> G[暂停接收新意向，保留队列和口令码]
    G --> H{卖家是否解冻}
    H -- 否 --> G
    H -- 是 --> E
    F -- 等待买家提交 --> I[买家免注册提交姓名和电话]
    I --> J[系统生成唯一口令码，按提交时间进入 FIFO 队列]
    J --> E
    F -- 处理等待意向 --> K{作废或移到队尾}
    K -- 作废 --> L[移出队列，口令码失效]
    K -- 移到队尾 --> M[刷新排队时间，原口令码继续有效]
    L --> E
    M --> E
    F -- 开始交易 --> N[系统自动选择有效队首]
    N --> O[商品交易冻结；队首意向进入交易]
    O --> P[拒绝新意向；其他等待买家仍可查询、修改或撤销]
    P --> Q[买卖双方线下交易]
    Q --> R{卖家登记交易结果}
    R -- 成功 --> S[本次意向交易成功；其余等待意向交易失败]
    S --> T[相关口令码失效，商品下架，删除视频]
    R -- 失败并作废 --> U[记录失败与作废，当前意向退出队列，口令码失效]
    R -- 失败并重新排队 --> V[记录失败与重排，同一意向及原码移到队尾]
    U --> W[商品恢复在售，不自动开始下一笔交易]
    V --> W
    W --> E
    F -- 主动下架 --> X[终止等待意向，相关口令码失效，删除视频]
    X --> Y[商品下架]
    T --> Z[可发布下一件商品]
    Y --> Z
```

主动下架只允许在商品可售且没有进行中的交易时执行；手动冻结须先解冻，交易冻结须先登记结果。每次提交、撤销、队列调整及交易结果都应写入该商品的业务记录。

## 2. 买家浏览、排队与口令码操作

```mermaid
flowchart TD
    A[访客打开商品页面] --> B{商品是否可浏览}
    B -- 无当前商品 --> C[显示暂无商品]
    B -- 有当前商品 --> D[查看名称、价格、描述及可选图片和视频]
    D --> E{商品是否在售并接收意向}
    E -- 否 --> F[显示暂不可申请；已有买家仍可用口令码查询]
    E -- 是 --> G[填写姓名和联系电话]
    G --> H{必填项是否完整}
    H -- 否 --> G
    H -- 是 --> I[提交意向并取得唯一口令码]
    I --> J[买家自行保存口令码]
    F --> K[输入已有口令码]
    J --> K
    K --> L{口令码是否有效}
    L -- 否 --> M[提示无效或已失效]
    L -- 是 --> N{意向状态}
    N -- 排队中 --> O[查看排位与商品状态]
    O --> P{买家操作}
    P -- 修改姓名或电话 --> Q[更新信息，排位与原码不变]
    Q --> O
    P -- 撤销 --> R[退出队列，原码立即失效，后续排位前移]
    P -- 继续等待 --> K
    N -- 交易中 --> S[可查询状态，不能撤销]
```

“排队中”的买家即使遇到商品手动冻结或其他买家的交易冻结，也仍可修改联系信息或撤销。已经进入交易的买家不能撤销。

## 3. 卖家后台与历史记录

```mermaid
flowchart TD
    A[卖家使用唯一账号登录] --> B[后台工作台]
    B --> C{功能区}
    C -- 商品管理 --> D[发布或编辑当前商品]
    D --> E[维护分类、标签、图片和展示视频]
    C -- 商品状态 --> F[手动冻结、解冻或主动下架]
    C -- 意向队列 --> G[查看姓名、电话、提交时间、状态及排位]
    G --> H[作废等待意向或移到队尾]
    C -- 交易操作 --> I[开始队首交易并登记成功或失败]
    C -- 账号管理 --> J[校验旧密码并设置不少于 8 位的新密码]
    C -- 历史查看 --> K[按商品查看只读历史及分页详情]
    H --> L[写入队列事件和对应时间]
    I --> M[写入交易结果与失败处置]
    F --> N[写入冻结、解冻或下架事件]
    L --> K
    M --> K
    N --> K
```

历史按商品组织。发生过交易失败的商品，即使随后恢复在售，也应在历史中保留失败流水；重新排队仍属于同一买家意向，历史需保留每次排队与重排事件。历史展示姓名、电话和业务结果，不展示口令码，定稿后只读。

## 4. 商品发布与媒体处理

```mermaid
flowchart TD
    A[卖家填写商品资料] --> B{名称非空且价格大于零、最多两位小数}
    B -- 否 --> C[提示修改必填信息或价格]
    C --> A
    B -- 是 --> D[可选：设置最多两级分类与多个标签]
    D --> E{是否上传图片}
    E -- 是 --> F{最多一张 JPG 或 PNG 且不超过 5 MB}
    F -- 否 --> G[提示格式、数量或大小不符合要求]
    G --> E
    F -- 是 --> H{是否上传展示视频}
    E -- 否 --> H
    H -- 是 --> I{文件不超过 100 MB 且时长不超过 2 分钟}
    I -- 否 --> J[提示修改视频文件]
    J --> H
    I -- 是 --> K[保存资料并发布商品]
    H -- 否 --> K
    K --> L[商品在售，买家可浏览]
    L --> M{商品是否交易成功或主动下架}
    M -- 否 --> L
    M -- 是 --> N[删除展示视频文件；保留商品及交易历史]
```
