# 在线购物系统子系统划分说明

版本V3.0；修订日期2026-10-24。沿用原五个子系统，第三轮扩展商品、分类、库存与客户能力。

## 1 子系统职责

| 编号 | 子系统 | 主要职责 |
| --- | --- | --- |
| S1 | 买家交互 | 访客商品浏览搜索分类、口令码操作；客户注册登录、默认地点确认和本人购买历史。 |
| S2 | 卖家工作台 | 多商品管理、分类管理、库存管理、商品级队列交易、改密及客户管理历史查询。 |
| S3 | 商品与媒体 | 商品持久化、两级分类、库存与售罄状态、最多9张相册及富媒体清理和展示。 |
| S4 | 购买意向与交易 | 按商品FIFO、冻结、姓名电话修改、撤销与交易；客户归属、下单地点和名称价格快照。 |
| S5 | 数据与公共支持 | H2、JPA、独立角色会话、PBKDF2、统一错误、文件上传、分页DTO及数据隔离。 |

## 2 调用边界

S1/S2通过HTTP接口访问S3/S4；S3/S4使用S5的持久化、鉴权与统一错误。客户注册和登录由CustomerController及CustomerService提供；客户历史从服务端会话取得客户编号；卖家客户查询由SellerCustomerController提供并经过既有卖家拦截器。

## 3 前后端对应

| 功能 | 前端入口 | 后端服务 |
| --- | --- | --- |
| 商品浏览和意向 | StorefrontView、catalogApi、customerApi | CatalogController、PublicController、StoreService |
| 卖家商品与分类 | SellerDashboardView、SellerCategories | SellerController、CatalogController、CatalogService |
| 客户账号 | CustomerAuthView、customerSession | CustomerController、CustomerService、CustomerRepository |
| 客户历史 | CustomerAccountView | CustomerController、CustomerService、IntentRepository |
| 卖家客户管理 | SellerCustomers | SellerCustomerController、CustomerService |
| 密码和会话 | SellerLoginView、账号管理、客户登录 | SellerCredentialService、PasswordHasher、SellerAuthInterceptor |

## 4 数据与协作

products关联categories和purchase_intents，customer_accounts可关联多条purchase_intents；访客customer_id为空。客户历史价格名称在提交时保存快照。卖家和客户会话身份分离，任何DTO不返回密码哈希。

## 5 三轮验收归属

首轮为基础购物意向闭环；第二轮为联系信息修改、手动冻结解冻、卖家改密；第三轮为A.1商品升级与A.2客户升级。完整接口及返回模型见后端接口说明，详细功能和接口测试见tests目录。
