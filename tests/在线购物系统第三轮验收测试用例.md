# 在线购物系统第三轮验收测试用例

版本 V3.3；整理日期 2026-10-24。本版按实际验收轮次整理，采用一个总测试方案、总用例清单及逐项详细实例。

## 总测试方案

验收范围：第三轮挑战需求A.1商品升级与A.2客户升级。

目录为 `第三轮验收测试数据/功能测试或接口测试/总用例编号/第n个测试实例/`。每个总用例至少8个详细实例。共128个实例：接口64个，功能64个。

环境：Java17、Maven3.6.3+、Node22+、Vue3与Element Plus；接口使用JUnit5、MockMvc及独立内存H2，每例清理测试数据，卖家初始admin/123456。页面测试应使用独立业务数据目录，避免修改日常data。

执行：`tests/run-iteration3-tests.cmd`；全部回归运行`tests/run-tests.cmd`。接口请求体从各实例请求JSON读取，上传从实例目录真实文件读取。动态编号、口令码和图片地址通过前一步响应capture变量传递，不能手填固定编号。

通过标准：请求状态码和响应字段逐项与断言一致；页面操作、提示、状态与预期一致并保存实际记录。退出标准：本轮接口无失败，页面实例全部人工执行后另行确认；当前不把未执行的页面用例标为通过。

## 测试设计方法

| 方法 | 本项目中的具体使用 |
| --- | --- |
| 等价类划分 | 将输入分为合法和不合法类别，分别选择代表数据。 |
| 边界值分析 | 检查长度、数量和金额边界及相邻值，例如库存-1、0、1，图片0、1、9、10张。 |
| 状态转换 | 按在售、手动冻结、交易中、下架及意向状态检查允许和禁止的操作。 |
| 场景法 | 按用户完整业务路径组织多步操作，并检查结果及历史记录。 |
| 权限隔离 | 分别使用访客、客户甲、客户乙和卖家会话，检查数据归属及访问限制。 |
| 兼容性与恢复 | 检查既有记录读取、页面尺寸和服务重启后的保存状态。 |

极限输入通过边界值分析体现，不把本次字段边界测试称为性能压测。本版未执行并发压力、长时间稳定性和浏览器全量自动化，不以这些名称描述结果。
