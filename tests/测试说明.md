# 首轮验收测试说明

## 1. 测试目的与依据

本测试用于证明首轮验收的基础业务闭环可以运行：卖家发布当前商品，买家免注册提交意向并按先到先得顺序排队，卖家处理交易，买家使用口令码查询状态。用例以项目中的《在线购物系统首轮验收基础需求》为业务依据，并参考课程的[系统验收标准](https://github.com/sebestp/coursewise/wiki/%E7%B3%BB%E7%BB%9F%E9%AA%8C%E6%94%B6%E6%A0%87%E5%87%86)整理。

自动化测试主要检查后端接口和状态流转。它使用 MockMvc 调用真实控制器、业务服务与数据库，不需要手动启动网页或后端。前端显示效果及服务重启后的数据保留另列人工检查步骤

## 2. 文件与运行方式

| 文件 | 用途 |
| --- | --- |
| `backend/src/test/java/cn/codelyy/store/StoreFlowIntegrationTest.java` | 首轮功能自动化集成测试，按 T01～T10 编号。 |
| `tests/run-tests.cmd` | 在 Windows 上进入后端目录并执行全部 Maven 测试。 |
| `tests/测试说明.md` | 记录目的、用例、运行办法、人工检查及已知差异。 |

准备 Java 17 及以上、Maven 3.6.3 及以上。打开 CMD，进入项目根目录后执行：

```bat
tests\run-tests.cmd
```

也可以直接执行：

```bat
cd backend
mvn test
```

## 3. 自动化测试用例

| 编号 | 内容与目的 | 主要步骤 | 预期结果 |
| --- | --- | --- | --- |
| T01 | 卖家身份与权限；防止未登录者操作后台 | 未登录访问后台、错误密码登录、正确登录、退出后再次访问 | 未登录和错误密码返回 401；登录后可访问；退出后权限失效。 |
| T02 | 商品发布与单件限制；确保买家看到正确商品 | 缺失必填字段发布、正常发布、再次发布、编辑、公开查询 | 无效数据返回 400；发布进入在售；第二件返回 409；修改后公开页面读到新内容。 |
| T03 | 购买意向、口令码与 FIFO；防止插队或无效口令码继续使用 | 三位买家提交；撤销中间买家；卖家把队首移至队尾并作废另一意向 | 口令码互不相同；排位按规则变化；撤销和作废后口令码立即失效；重排保留原码。 |
| T04 | 交易冻结与撤销边界；保证只有队首进入交易 | 卖家开始交易；新买家尝试提交；交易中买家尝试撤销；等待买家撤销 | 自动选择队首；商品进入交易中且不接收新意向；交易中买家不能撤销；等待买家仍可撤销。 |
| T05 | 交易失败并作废；保证流程可继续 | 卖家登记交易失败并作废当前买家 | 商品恢复在售；当前码失效；下一位继续排队，系统不自动开启新交易。 |
| T06 | 交易失败并重新排队；保证买家无需重新提供信息 | 卖家登记交易失败并选择排到队尾 | 原口令码仍可查询；原意向回到排队中，排到队尾；商品恢复在售。 |
| T07 | 交易成功后的收尾；防止商品和口令码继续使用 | 卖家登记成功，查询本次和剩余意向，再发布下一件 | 商品下架；本次意向成功、未轮到的意向失败；相关口令码失效；可以发布下一件。 |
| T08 | 卖家主动下架；防止下架商品继续接单 | 有等待买家时卖家下架商品，再查询口令码并发布下一件 | 商品不可浏览；相关口令码失效；可以发布下一件。 |
| T09 | 图片上传及首轮单图上限；限制文件类型、大小和数量 | 上传 JPG、PNG、非图片文件和超过 5 MB 的图片；分别将 1 张、2 张图片关联商品 | JPG/PNG 返回上传地址；错误格式和超大文件返回 400；1 张可保存，2 张被拒绝。 |
| T10 | 兼容旧版本已经保存的多图商品；保证首轮页面只展示一张 | 在测试数据库中准备旧版多图记录，再查询当前商品接口 | 接口只返回第一张图片；原数据库记录和上传文件不在读取时自动删除。 |

## 4. 网页与持久化人工检查


| 编号 | 检查目的与步骤 | 预期结果 | 实际结果 |
| --- | --- | --- | --- |
| U01 | 打开买家首页，不登录；卖家登录并发布无图片商品，再刷新买家页 | 买家可看到商品名称、价格和无图片占位；未发布前显示空状态 | 通过 |
| U02 | 买家不填姓名或电话提交；填完整后提交并保存口令码 | 空值有提示；提交成功只展示一次口令码，凭码可查询排位 | 通过 |
| U03 | 两位买家依次提交；卖家查看后台队列并开始交易 | 后台按顺序显示姓名、电话、提交时间和状态；仅队首进入交易 | 通过 |
| U04 | 交易期间，让等待买家撤销，再让交易中买家尝试撤销 | 等待买家能退出；交易中买家不能撤销；页面排位更新 | 通过 |
| U05 | 关闭并重新启动后端，继续查询尚有效的口令码 | 当前商品、有效意向与顺序保留 | 通过 |
| U06 | 选择一张商品图片后尝试再选第二张；上传错误格式及大于 5 MB 的图片 | 当前商品最多显示和保存一张图片；错误格式或超大图片有提示；无图片时仍可发布 | 通过 |
| U07 | 分别在桌面和窄屏浏览器查看买家页、卖家登录页及后台侧边目录 | 页面内容可阅读，按钮可操作，没有遮挡 | 通过 |
