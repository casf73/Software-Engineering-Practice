# 第四轮测试说明

本轮验收挑战需求 B 与个性化在线定制，覆盖购物车、收藏、订单状态、取消及库存、定制设计和匠人制作进度。网页功能测试使用独立演示账号；自动化使用独立内存 H2。

## 总测试方案

| 类型 | 范围 | 实例数 | 执行方式 | 执行记录 |
| --- | --- | --- | --- | --- |
| 功能测试 | R401～R406，每组 8 例 | 48 | 浏览器人工验收 | 48 例待人工执行 |
| 综合接口测试 | R401～R406，每组 8 例 | 48 | MockMvc + 独立 H2 | 48/48 通过 |
| 单接口测试 | API-01～API-17，每个接口 5 例 | 85 | MockMvc + 独立 H2 | 85/85 通过 |

| 编号 | 验收内容 |
| --- | --- |
| R401 | 购物车与勾选结算 |
| R402 | 收藏与单向移动 |
| R403 | 订单状态推进 |
| R404 | 整单取消与库存 |
| R405 | 在线定制与方案快照 |
| R406 | 匠人资料与制作进度 |

功能验收按步骤核对页面、状态及库存。接口验收同时校验 HTTP 状态和指定 JSON 字段；整单失败时还要核对库存、订单和购物车。

浏览器冒烟已验证勾选合并下单、保留未选商品、转收藏、定制预览与确认下单、匠人资料、制作时间轴、客户发货后取消限制及卖家取消库存回补。功能测试工作表保留 48 条逐例人工验收记录位。

## 运行与查阅

在 Windows 仓库根目录运行 `tests\run-iteration4-tests.cmd`。使用 Java 17、Maven 和 UTF-8。自动化原始结果位于 `project/mvp-v1.0/backend/target/acceptance-results/4`。

网页验收使用测试数据库。准备客户甲、客户乙和卖家三个登录会话，再建立甲「手工木牌」20 元、乙「手工相框」12 元、丙「手工钥匙扣」8 元，默认在售且各 3 件。按每个实例的前置条件调整库存、账号和状态，每例从独立数据开始。定制相关实例可为甲启用定制，填写匠人「木作工坊」和简介「手工打磨，逐件制作。」。

## 用例设计方法

等价类划分覆盖有效与无效输入，边界值分析覆盖库存 0/1、文字 60/61 和取消临界状态，状态转换覆盖正常推进与非法迁移，场景法覆盖多商品与定制流程，权限隔离验证不同身份，事务一致性和幂等性验证失败回滚及重复请求，快照测试验证历史数据。
