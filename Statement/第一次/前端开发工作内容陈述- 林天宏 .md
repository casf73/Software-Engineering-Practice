## 1. 项目背景与工作目标

本项目实现单卖家场景下的购物排队闭环：买家免注册填写姓名电话即可进入FIFO先到先得队列，卖家通过后台管理商品、处理交易流程。我的核心工作目标是：**完成全部前端页面开发与交互实现，与后端接口完成联调对接，实现符合需求的买家端、卖家端双端完整功能，保证页面交互流畅、布局适配正常、表单校验与状态提示准确，支撑首轮验收流程顺畅走通。**

工作覆盖从前端工程初始化、页面组件开发、接口联调、交互细节优化、构建打包验证的全流程前端开发工作。

## 2. 具体工作内容与职责范围

### 2.1 前端工程初始化与基础配置
1.  基于Vite搭建Vue3工程，完成项目目录规范搭建，配置Vue Router路由规则
2.  集成Element Plus组件库、Axios请求库，配置前端开发代理，将`/api`、`/uploads`请求转发到本地后端8080端口
3.  封装通用请求工具，统一配置请求携带会话Cookie、统一错误提示拦截，处理跨域与会话保持问题
4.  完成公共全局样式、基础布局组件封装，统一页面风格与交互规范

### 2.2 买家端页面开发
实现面向普通买家的全流程前端交互，对应路由路径`/`：
1.  **商品展示模块**：完成商品卡片组件开发，支持商品名称、价格、描述、图片展示；无商品时展示空状态提示；商品交易中状态下展示对应提示并禁止新意向提交
2.  **购买意向提交模块**：实现姓名、联系电话表单，完成前端必填校验、提交加载状态处理；提交成功后弹出口令码弹窗，提供一键复制口令码功能
3.  **口令码查询模块**：实现口令码输入框与查询逻辑，展示买家意向状态、当前排位、对应商品状态；仍在排队的买家支持主动撤销意向操作，交易中买家撤销操作做拦截提示

### 2.3 卖家端页面开发
实现卖家后台全管理功能，对应路由路径`/seller/login`、`/seller/dashboard`：
1.  **卖家登录页**：实现账号密码登录表单，对接后端登录接口，登录成功后路由跳转到管理后台，错误提示做对应展示
2.  **卖家后台侧边导航**：实现概览、商品管理、购买意向三个核心菜单的路由切换，提供退出登录功能
3.  **工作台概览页**：对接后端工作台接口，展示当前商品信息、等待人数、当前交易状态
4.  **商品管理模块**：
    - 支持新商品发布：包含名称、价格必填字段校验，描述、图片选填上传功能
    - 支持已有商品编辑：交易中状态下自动禁用编辑操作，做操作拦截
    - 图片上传交互：支持JPG/PNG单张上传，前端做格式与大小预校验，提示上传结果
    - 商品主动下架操作：交易中状态下禁用下架按钮
5.  **购买意向队列管理模块**：
    - 按排队时间顺序展示所有等待买家的姓名、电话、排队时间、当前状态
    - 实现单条意向的作废、排到队尾操作，带二次确认弹窗
    - 实现一键开启与队首买家交易的操作入口
    - 实现交易结果登记功能：交易成功/失败两个分支，失败时引导选择作废或重新排队到队尾

### 2.4 公共组件与交互封装
按组件复用原则，在`frontend/src/components/common`下封装全项目通用组件：
1.  `AppHeader`：全局页面头部导航组件
2.  `PageHeader`：子页面标题栏组件
3.  `AppCard`：通用内容卡片容器组件
4.  `StatusBadge`：业务状态彩色标签组件，统一展示不同排队/交易/商品状态
5.  `ProductImage` / `ProductGallery`：商品图片展示组件
6.  `EmptyState`：列表/内容为空状态的统一占位组件
7.  `AppDialog`：基于Element Plus Dialog封装的通用弹窗组件，支持自定义标题、正文、底部操作按钮，统一全项目确认弹窗交互风格

### 2.5 前端联调与体验优化
1.  对接全部12个后端业务接口，完成接口请求参数、返回数据渲染、异常错误提示的全链路打通
2.  所有需要用户确认的破坏性/状态变更操作（撤销意向、作废、下架、开始交易）统一使用二次确认弹窗，避免误操作
3.  响应式布局适配：完成桌面端与窄屏浏览器下的页面布局调整，保证侧边栏、表单、按钮在小屏幕下无遮挡、可正常点击
4.  页面加载、接口请求、提交成功/失败的状态提示与加载态处理，优化交互体验
5.  执行`npm run build`生产构建验证，确认前端无构建错误，可正常打包部署

## 6. 工作边界与协作说明

1.  本工作范围覆盖首轮验收全部前端页面与交互实现，不包含前端自动化单元测试、前端性能优化、SEO相关工作

4.  页面UI视觉风格按Element Plus默认主题实现，未做品牌化定制设计
