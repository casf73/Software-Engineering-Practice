# 第二轮功能说明

版本 V2.2，更新日期 2026-10-22。本轮成果展示三项基础功能完善。

## 功能与验收范围

| 编号 | 功能 | 页面入口 | 实现规则 |
| --- | --- | --- | --- |
| I2-01 | 等待买家修改联系信息 | 买家首页口令码查询与修改 | 修改姓名和电话，保留意向编号、口令码及排位；交易中的买家不能修改。 |
| I2-02 | 卖家手动冻结与解冻 | 卖家商品工作台 | 冻结阻止新意向、保留队列；解冻恢复在售；交易冻结不能手动解除。 |
| I2-03 | 卖家修改密码 | 卖家账号管理 | 校验原密码，保存带随机盐的密码哈希并撤销旧会话；重启不重置密码。 |

等待者在手动冻结或他人交易期间仍可修改联系信息；卖家队列展示更新后的姓名与电话。

## 运行与成果物

开发运行：在 `backend` 执行 `mvn spring-boot:run`，在 `frontend` 执行 `npm run dev`，访问 `http://localhost:5173`。

集成运行：进入 `release-iteration2`，执行 `java -jar app.jar`，访问 `http://localhost:8080`。数据默认保存在启动目录的 `data`，需要保留数据库与上传文件。
