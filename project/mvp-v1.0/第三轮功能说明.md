# 第三轮功能说明

版本V3.0；日期2026-10-24。第三次迭代验收挑战需求A.1与A.2。前两轮功能继续回归；开发源码沿用project/mvp-v1.0目录。

## 功能与验收范围

| 编号 | 功能 | 前端入口 |
| --- | --- | --- |
| R301 | 多商品发布和独立队列 | 商品管理、商品首页 |
| R302 | 一级二级分类 | 分类管理、商品分类选择 |
| R303 | 库存及售罄自动下架 | 商品库存、交易结果登记 |
| R304 | 浏览、关键词搜索和分类分页 | 商品首页 |
| R305 | 多图和富媒体描述 | 商品编辑、图片相册 |
| R306 | 客户注册登录及默认交易地点 | /customer/register、/customer/login |
| R307 | 客户购买历史及账号隔离 | /customer/account |
| R308 | 卖家客户信息及历史查询 | 卖家后台客户管理 |

## 运行

后端目录运行mvn spring-boot:run；前端目录运行npm ci和npm run dev；打开http://localhost:5173。新增客户注册、登录、我的购买入口和后台客户管理。

release和release-iteration2中的JAR、旧ZIP以及Docker镜像是历史版本；本次更新源码和文档测试，没有把旧包重标为第三轮发布。
