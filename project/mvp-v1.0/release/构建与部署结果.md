## 已完成

1. 将本机 nvm 默认 Node.js 从 16.20.2 切换至已安装的最高版本 24.17.0。
2. 使用 `scripts/build.ps1 -SkipNpmInstall -MavenOffline`，完成前端 Vite 生产构建与后端 Spring Boot 打包；Maven 报告 `BUILD SUCCESS`，测试执行被跳过。

4. 使用 `release/install.ps1` 安装至 `deployment-local`，以 `127.0.0.1:18080` 启动服务。
5. 对 `/` 和 `/seller/login` 发起本机 HTTP 请求，两个页面均返回 200。

## 本机部署

当前本机服务地址：<http://127.0.0.1:18080/>。部署目录为 `project/mvp-v1.0/deployment-local`，日志位于其 `logs` 目录，数据位于 `data` 目录。停止时运行：

```powershell
& .\deployment-local\stop.ps1
```
