# 在线购物系统后端接口说明

文档版本 V2.2，2026-10-22。本页列出第二轮三项基础功能及相关支撑接口，不作为全部开发接口清单。

## 本轮接口总表

| 方法 | 接口 | 身份 | 作用 |
| --- | --- | --- | --- |
| GET | `/api/public/intents/{passcode}` | 持口令码 | 查询姓名、电话、状态及排位 |
| PUT | `/api/public/intents/{passcode}` | 持口令码 | 修改等待买家姓名与电话 |
| DELETE | `/api/public/intents/{passcode}` | 持口令码 | 撤销等待中的意向 |
| GET | `/api/seller/products/{id}/workbench` | 卖家 | 展示联系信息、等待队列和交易对象 |
| POST | `/api/seller/products/{id}/freeze` | 卖家 | 手动冻结商品，保留原队列 |
| POST | `/api/seller/products/{id}/unfreeze` | 卖家 | 解除手动冻结，恢复在售 |
| PUT | `/api/seller/password` | 卖家 | 校验原密码并保存新密码，撤销旧会话 |
| POST | `/api/seller/login` | 公开 | 建立卖家会话 |
| GET | `/api/seller/session` | 公开 | 查询会话状态 |
| POST | `/api/seller/logout` | 卖家 | 退出登录 |
| POST | `/api/seller/products/current/freeze` | 卖家 | 原路径冻结当前商品 |
| POST | `/api/seller/products/current/unfreeze` | 卖家 | 原路径解冻当前商品 |

## 通用约定

基址 `http://localhost:8080`；JSON 请求使用 `Content-Type: application/json`。卖家身份使用 HTTP Session Cookie。常见响应：200 查询成功；204 操作成功无响应体；400 参数不合法；401 身份无效；404 资源或有效口令码不存在；409 状态冲突。

## 联系信息修改

### 口令码操作

- `GET /api/public/intents/{passcode}` 返回 `name/phone/status/position/productStatus`，非等待状态 `position` 为空。
- `PUT /api/public/intents/{passcode}` 请求同提交意向；仅 `WAITING` 可改姓名和电话，保留口令码与原队列顺序。其他买家交易时、手动冻结时，等待者仍可改。
- `DELETE /api/public/intents/{passcode}`：仅等待者可撤销，返回 204，口令码清空。交易中买家不能撤销。
- 口令码忽略大小写、去除首尾空格，无效或失效返回 404。口令码属于持有者凭据，请自行保存。

### 卖家工作台与处理

`GET /api/seller/products/{id}/workbench` 返回 `product/intents/waitingCount/activeIntent`。意向行包含 `id/name/phone/status/position/queueAt`，交易对象排在前，等待意向按排队时间和编号排序。


## 手动冻结与解冻

`POST /api/seller/products/{id}/freeze` 只允许在售商品进入 `MANUALLY_FROZEN`，保留等待队列，暂停接收新意向和开始交易。

`POST /api/seller/products/{id}/unfreeze` 只解除手动冻结，恢复 `ON_SALE`。`IN_TRADE` 不能通过此接口解除。状态不允许返回 409，未登录返回 401。

旧路径 `products/current/freeze` 与 `products/current/unfreeze` 保留；需要当前商品上下文明确，无法唯一确定商品时返回 409。

## 密码修改与会话

`PUT /api/seller/password` 请求示例：

```json
{"currentPassword":"旧密码","newPassword":"至少8位新密码"}
```

校验原密码后保存随机盐 PBKDF2 密码哈希，成功返回 204，注销当前 Session 并递增会话版本，使旧卖家会话失效。重启不会恢复初始密码。

`POST /api/seller/login` 使用 `username/password`，返回 `authenticated`；`GET /api/seller/session` 查询登录状态；`POST /api/seller/logout` 成功返回 204。
