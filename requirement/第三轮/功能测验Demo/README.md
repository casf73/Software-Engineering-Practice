# 第三轮功能需求测验 Demo

## 打开方式

双击本目录的 `index.html`，直接在现代浏览器中打开。Vue 3、Element Plus和示例图片均在本目录，离线可用，不需要安装依赖、启动项目或连接后端。分享时复制整个文件夹。

## 新增功能范围

| 新增需求 | 体验位置与操作 |
| --- | --- |
| A.1 多商品 | 商品管理中同时保留多件商品，分别点击独立队列查看示例。 |
| A.1 两级分类 | 分类管理新增一级或二级分类；在商品表单选择，在浏览页筛选。 |
| A.1 库存与下架 | 对库存为1的商品点击模拟成交1件，观察售罄下架；点击补货上架恢复。 |
| A.1 浏览搜索 | 搜索名称或描述，如键盘、办公；筛选一级或二级分类，体验分页。 |
| A.1 多图和富文本 | 商品详情切换缩略图；编辑商品上传本地图片，使用加粗、斜体、标题、列表和插入描述图片。 |
| A.2 注册登录 | 注册一个本页临时客户，或使用预设账号登录；包含电话和默认交易地点。 |
| A.2 我的购买 | 直接切换客户查看各自的预设历史；可从详情添加一条模拟记录，体验本次地点及名称价格快照。 |
| A.2 卖家客户管理 | 按用户名或电话筛选客户，查看客户信息和对应历史。 |

## 演示账号与预置场景

- 客户buyer01和buyer02，演示密码均为demo12345，页面初始选中buyer01。
- 每个客户有独立的历史示例，包含排队、成功或撤销状态。
- 卖家模块直接可用，不需要先登录。
- 软件工程学习书籍、算法学习手册的初始库存为1，可直接演示售罄。
- 备用阅读台灯的初始库存为0，可直接演示补货。

## 模拟方式

此Demo只展示第三次迭代新增功能，不重复演示前两轮联系信息修改、冻结解冻和卖家改密。

所有账号、商品、分类和购买记录只在当前页面内存中保存。刷新或点击重置演示恢复预置数据；不连接接口、数据库、真实账号或正式项目数据。只保留演示所需的基础必填、数量和状态判断，没有完整校验、权限认证或完整交易流程。

“模拟成交1件”直接减库存，“模拟添加到我的购买”直接增加示例记录且不扣库存；两者独立用于说明需求，不代表完整的订单或排队业务流转。预设历史不会随着商品编辑改变名称和价格。

## 文件

- index.html：Element Plus页面与对话框。
- app.js：本页示例数据与模拟交互。
- style.css：白底、表单、表格及响应式布局。
- vendor：沿用第二轮Demo的本地Vue和Element Plus资源。
- assets：本地商品示意SVG，便于离线切换相册。
