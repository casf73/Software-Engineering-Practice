  1. 商品浏览：搜索、分类筛选、翻页，打开详情切换多张图片。
  2. 商品管理：独立发布多件商品；对库存为1的商品模拟成交，观察自动下架；可以补货。
  3. 编辑商品：上传图片、编辑富文本、选择两级分类。
  4. 分类管理：增加一级或二级分类，观察商品分类选择联动。
  5. 客户注册与登录：创建临时客户或使用 buyer01 / demo12345。
  6. 我的购买与卖家客户管理：切换预设客户，比较各自的历史记录。

本页直接在内存中模拟界面变化，没有接口、数据库或生产账号；各模块可单独体验，刷新会清空临时操作。
