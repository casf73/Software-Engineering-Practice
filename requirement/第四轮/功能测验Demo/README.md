# 第四轮功能测验 Demo

用于项目经理演示挑战需求 B 与定制礼品。保留整个目录，直接用 Edge 或 Chrome 打开 `index.html`。Vue 与 Element Plus 随包提供，可以离线打开。页面使用模拟商品、库存和订单，不需要启动后端、登录项目账号或连接数据库。刷新页面或点击「重置演示」即可恢复数据。

## 建议演示顺序

1. **购物车、收藏与选中结算**。勾选手工木牌和手作相框，点击「结算所选商品」，确认后检查一笔订单包含两种商品。回到购物车，编织钥匙扣仍在。将钥匙扣转收藏，确认它从购物车移除，收藏中的已下架陶瓷书签也仍保留。
2. **订单状态与取消**。在订单页切换到卖家视角，依次点击「商家确认」「备货完成」「开始发货」。切回客户视角查看时间轴，此时取消入口已隐藏。切回卖家视角点击「取消整单」，确认订单变为已取消，各商品库存回补。若要演示客户取消，重新下单并在发货前操作。
3. **在线定制与匠人制作**。从手工木牌的商品详情点击「开始定制」，选择模板、填写文字并调整图案与配色。可用「填入示例方案」快速展示。打开「匠人主页」查看作品资料，确认方案后生成独立定制订单。在订单页切到卖家视角推进状态，再回客户视角查看制作与订单时间轴。
4. **库存不足**。重置后把编织钥匙扣数量改为 2，再和另一件商品一起勾选结算。确认系统提示库存不足，购物车、库存与订单均保留原状。
