# 第二轮需求补充说明

版本 V2.3，整理日期2026-10-24。第二轮仅验收以下三项基础改进；挑战需求A.1和A.2在第三轮交付，不回填为第二轮完成项。

| 编号 | 需求 |
| --- | --- |
| R201 | 等待买家凭口令码修改姓名和电话，保留原编号、口令码和排位；手动冻结和他人交易期间仍可改，当前交易者不能改。 |
| R202 | 卖家手动冻结保留等待队列、拒绝新意向；手动解冻恢复在售，不能手动解除交易冻结。 |
| R203 | 改密校验当前密码，新密码8～128位；PBKDF2加盐持久化，修改后旧卖家会话失效。 |

对应测试包含功能测试和接口测试，每总用例各8个实例。
