# 第二轮需求补充说明

版本：V2.1；日期：2026-10-22。整理人：麻津午。

本说明补充首轮需求基线，统一第二轮术语、三项基础改进及挑战需求 A.1。旧文档的“唯一当前商品”“最多一张图片”“每次成交一律下架”由本说明中的多商品、多图与库存规则替代。A.2 客户升级不在本轮交付范围内。

## 术语表

| 项目 | 说明 |
| --- | --- |
| 买家（访客） | 无需注册即可浏览、搜索商品，填写姓名和电话提交意向，凭口令码管理本人意向。 |
| 卖家 | 唯一后台账号，管理多个商品、两级分类、各商品队列及交易结果。 |
| 商品编号 | 区分商品的唯一编号，浏览、编辑、冻结和交易均按指定商品操作。 |
| 当前选中商品 | 卖家在列表中选中的商品；可同时存在多个有效商品，不再指唯一上架商品。 |
| 购买意向与 FIFO | 每条意向对应 1 件指定商品；每件商品独立按排队时间、编号升序形成等待队列。 |
| 口令码 | 对应单条购买意向的查询和操作凭据，意向结束后按规则失效。 |
| 手动冻结与交易冻结 | 手动冻结暂停新意向并保留队列，可手动解冻；交易冻结需先登记交易结果。 |
| 库存与售罄下架 | 成功交易扣减 1 件；有余量恢复在售，归零后自动下架并结束其他等待意向。 |
| 两级分类 | 一级分类可包含二级分类；一级筛选包含其子类，禁止三级、循环及同级重名。 |
| 多图与富媒体描述 | 每商品最多 9 张 JPG/PNG，每张不超过 5 MB；描述支持格式化文字和本地图片。 |

## 基础功能需求补充

| 项目 | 说明 |
| --- | --- |
| 等待期间修改联系信息 | 买家凭口令码修改等待意向的姓名、电话，保留编号、口令码、提交时间和排位。 |
| 冻结期间的买家操作 | 商品手动冻结或与其他买家交易时，等待者仍可修改或撤销；交易中的买家不能修改或撤销。 |
| 卖家手动冻结与解冻 | 按商品暂停新意向，已有等待队列保留；须先解冻才能开始交易或主动下架。 |
| 卖家修改密码 | 验证当前密码；新密码 8～128 位；随机盐 PBKDF2 哈希持久化，修改后旧登录会话失效。 |

## 挑战需求 A.1

| 项目 | 说明 |
| --- | --- |
| A.1-1 多商品同时发布 | 允许同时发布多个商品；每件商品独立库存、状态、等待队列与交易对象。 |
| A.1-2 两级类别管理 | 新增、修改和删除一级、二级分类；商品可关联分类；已引用的分类不能直接删除。 |
| A.1-3 库存与自动下架 | 库存为 0～1000000 整数；单次成交扣减 1 件，库存归零下架，失败不扣库存；补货后可重新上架。 |
| A.1-4 浏览和搜索 | 分页浏览，按名称或描述关键词搜索；支持一级或二级分类筛选。 |
| A.1-5 多图与富媒体 | 商品相册最多 9 张图片；可切换缩略图；描述支持标题、段落、粗体、斜体、列表与本地上传图片。 |
