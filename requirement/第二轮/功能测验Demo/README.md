# 第二轮功能需求测验 Demo

## 打开方式

双击本目录的 `index.html`，在浏览器中打开。Vue 3 与 Element Plus 资源放在 `vendor` 目录，不需要联网、安装依赖或启动后端。移动或分享时请复制整个目录。

## 演示范围

| 功能 | 体验方式 |
| --- | --- |
| 修改联系信息 | 买家视角查询 DEMO002，修改姓名和电话；切到卖家视角确认同步更新，排位、口令码和提交时间保持。 |
| 手动冻结与解冻 | 卖家视角冻结商品，确认原队列保留、新意向入口禁用，等待者仍可修改或撤销；解冻后恢复提交。 |
| 交易状态边界 | 场景栏切换他人交易中、本人交易中；等待者仍可修改，当前交易者不能修改或撤销。 |
| 修改卖家密码 | 账号页输入当前密码 123456 和任意非空新演示密码，确认后保存，模拟旧会话失效，再使用新密码登录。 |

三个演示口令码为 DEMO001、DEMO002、DEMO003。默认卖家已登录，账号 admin，初始演示密码 123456。

场景切换重新载入商品和队列，保留本页密码与登录状态；“重置演示”恢复全部初始状态；刷新页面也会恢复初始状态。

## 使用边界

此 Demo 用于需求人员提前讨论操作流程，不连接真实前后端、数据库或项目账号。只做简单的必填、密码一致性和状态判断，不做完整格式校验或生产级认证。密码仅保存在页面内存，请勿输入真实密码。

“结束模拟交易”是场景辅助按钮，仅将交易买家恢复到原演示队列，不代表真实交易结果处理。Demo 不包含挑战需求功能。

## 文件

- index.html：Element Plus 页面与交互模板。
- style.css：白底布局、表格、表单与移动端样式。
- app.js：Vue 状态及模拟业务操作。
- vendor/：从本项目已有依赖复制的 Vue 和 Element Plus 资源，未修改其内容。

源码版本参考：本项目现有 Element Plus 2.14.6。本任务未修改正式业务页面或后端源码。
